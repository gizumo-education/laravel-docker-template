# Laravel Lesson レビュー①

## Todo一覧機能

### Todoモデルのallメソッドで実行しているSQLは何か
todoController.php 13行目 $todos = $todo->all();にてtodosテーブル全てのデータを取得するSQL
SELECT * FROM todos WHERE deleted_at IS NULL;


### Todoモデルのallメソッドの返り値は何か
複数のTodoデータをまとめた、LaravelのCollection

### 配列の代わりにCollectionクラスを使用するメリットは
データの検索・絞り込み・並び替えなどを用意されているメソッドを使って簡単に行うメリットがある。

### view関数の第1・第2引数の指定と何をしているか
第一関数：表示したいViewの名前
第二関数：Viewに渡したいデータ
controllerで取得したデータを、表示する画面へ渡している

### index.blade.phpの$todos・$todoに代入されているものは何か
$todos = 複数のTodoデータをまとめたcollection
$todo = 繰り返し処理で取り出した１件のデータ

## Todo作成機能

### Requestクラスのallメソッドは何をしているか
フォームなどから送られた入力データをまとめて取得している
### fillメソッドは何をしているか
配列で渡された複数のデータを、Model属性にまとめて設定している
### $fillableは何のために設定しているか
一括代入を許可する項目を指定し、意図しないデータを変更を防ぐために設定している
### saveメソッドで実行しているSQLは何か
新しいTodoを保存する場合、基本的にINSERT文が実行される
### redirect()->route()は何をしているか
指定した名前のルートに対応するURLへ、ブラウザをリダイレクトさせている
