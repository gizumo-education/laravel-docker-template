# Laravel Lesson レビュー①

## Todo一覧機能

### Todoモデルのallメソッドで実行しているSQLは何か
DBから取得したデータを全件画面表示する処理の実行
### Todoモデルのallメソッドの返り値は何か
todosの$todosに入っているデータを第一引数に指定されたindex(ビュー)に渡す処理
### 配列の代わりにCollectionクラスを使用するメリットは
それぞれのレコード情報を1つのインスタンスという形で取得できるため、処理が少なくすることができる。（id・content→ todoインスタンス）
### view関数の第1・第2引数の指定と何をしているか
第一引数で表示する場所をtodos・index(ToDo一覧画面)を指定して、第二引数で表示するデータの取得場所を指定している。
### index.blade.phpの$todos・$todoに代入されているものは何か
$todosにCollectionクラスが代入され、$todoにはtodoインスタンス1件ずつ代入されている。
## Todo作成機能

### Requestクラスのallメソッドは何をしているか
フォームで入力されたものを連想配列として取得する処理
### fillメソッドは何をしているか
Todoインスタンスの各プロパティに一括で代入をしている。
### $fillableは何のために設定しているか
ディベロッパーツールからの改ざんをされないように入力可能な欄を制限するため
### saveメソッドで実行しているSQLは何か
変更した内容を保存するための処理の実行
### redirect()->route()は何をしているか
変更した内容をDBに保存された後に、index.blade.phpのページにリダイレクトされる処理
## その他

### テーブル構成をマイグレーションファイルで管理するメリット
Gitで共有することで、他の人が同じテーブルを作成（複製）することができる
### マイグレーションファイルのup()、down()は何のコマンドを実行した時に呼び出されるのか
docker compose up -d、docker compose down
### Seederクラスの役割は何か
データベースに初期データやテストデータを一括で投入すること
### route関数の引数・返り値・使用するメリット
引数→遷移先のパス・ToDoController.phpの処理したいメソッドの指定
返り値→指定されているパスに遷移した際に毎回処理されるメソッド
メリット→URLの入力ミスを防ぎやすくなる。処理の内容が短いため可読性の向上
### @extends・@section・@yieldの関係性とbladeを分割するメリット
親bradeの継承のために必要で、指定した文字列を自動で代入されるようにすることができる関係性。
bladeを分割することで複数の開発者での作業を分けやすくなる。かつ、エラーの発見がしやすくなる。
### @csrfは何のための記述か
フォームを送信した際に、トークンが発行されリクエスト元が正しいかを確認するため
### {{ }}とは何の省略系か
表示したい変数の出力値
